## 1. 第二轮空间方案

### 1.1 取舍原则

- 苏式园林的空间关系：水面居中、建筑沿岸、围墙围合；主景对景（榭对北岸假山亭）、框景（柱和挂落框住水面）、借景（河道尽头的塔）、隔而不断（漏窗、月洞门）、曲折（水廊、曲桥）、高低（假山、两层楼、平廊、矮墙）。
- 克制：每处只留一种主要花样；植物按生长逻辑放（柳在水边、竹靠墙角、松在山石上、荷在浅水湾），不往每个空当里塞。
- 自然光是主光：傍晚偏阴（薄云里的斜阳）。阳光从西南低角度进榭，穿过西面美人靠、竹帘和南面槅扇，在地上落出光条；北岸朝南的粉墙被照暖。人工灯只留两盏，很暗。
- 统一像素密度：建筑、地面、石头按每米 16 像素；家具和细木作最多每米 32 像素；人物脸部仍是两倍密度（人物管线的既有约定）。

### 1.3 桌椅与周边空间

- 圆桌放在厅心 (16, 12.5)，直径 3.2 米、高 0.72 米；桌面边缘做薄（冰盘沿），桌下是六条细腿 + 牙板，不做到地的整圈裙板，**从桌下能看到地面**，不像一个木圆柱。
- 八席：椅子中心离桌心约 2.15 米（离桌沿约 0.55 米），每席弧长约 1.7 米；每席离桌远近差 ±5 厘米、转角差 ±4°。椅背到柱线约 2.7 米，走得开。
- 椅子和桌子同一种木料（`props/chairs.ts` 的 `GARDEN_WOOD`）、同一种马蹄足和牙板；座高沿用共用椅子族的 0.50（人物骨架定的），靠背顶 0.75（不顶到后脑），S 形靠背板，无扶手（手势不碰椅子），前面不设低枨（脚有地方放）。座垫只用一种素色。
- 桌面留空，不放茶具。

### 1.5 参考图取舍

保留并转化：
- 实景照片：深色、平静、有倒影的水面；粉墙、黛瓦、深栗色木作的克制色板；不规则的黄石驳岸和石缝植物；大树树冠压在水边和屋顶上；从暗的室内透过窗格看亮的园景（框景）；河道尽头一座小塔（借景，尺度很小）。
- 概念图：方块语言和细部尺度（细木作、栏杆、瓦垄）；亭里一张圆桌、同一套木椅；沿白墙的游廊和墙上的月洞门；石拱桥；阳光穿过窗格在地上落成图案；远景几层剪影。

删除或改掉：
- 到处都是的灯笼（柱上、栏杆上、桌上、桥上、岸边）：只留两盏、很暗。
- 桌上的茶具、桌下的藤席。
- 远处的宫殿山城、巨大宝塔：改成墙外林冠、两道屋脊、低山和一座很小的借景塔。
- 成片的白花：去掉；园里的花只有东北浅湾和小岛西南的两片荷。
- 从亭子梁上垂下来的柳丝：柳只长在岸上，柳丝从树冠垂下。

### 1.6 概念图里的建筑与空间逻辑错误（实现时避开）

1. 柳丝从亭子的梁枋、挂落里垂下来，附近没有树干。
2. 灯笼布满柱子、栏杆、桌面、桥面，白天也亮着。
3. 远处的宫殿群和高塔按幻想尺度放在山上，比园林本身还大。
4. 石拱桥一端接到灯火通明的岛上、另一端没有路；有的桥两头都悬在水里。
5. 台阶从平台直接下到深水里，没有埠头平台。
6. 屋顶层层叠叠，檐口和下面的柱子对不上；斗拱样式是北方官式，不是苏式；廊的屋顶直接插进亭子屋面。
7. 光的方向不统一：太阳在画面后方，前景却被正面照亮；柱子的影子朝几个方向散开。
8. 睡莲叶是一块块方瓦平铺在深水中央，密度和位置都不合理。
9. 家具尺度：扶手椅像沙发，桌子像茶几一样矮；石鼓桌巨大笨重。
10. 临水的湿石板地上铺藤席。
11. 水面几乎和台面平齐，没有出水高度。
12. 竹子从石板地面和亭子里长出来。

### 2.5 已知视觉问题（如实记录，不算“可以接受”）

- 墙外远景：林冠是一团团方块，远看可以，近一点就显得粗；高处往远看，地平线是一片平的雾色。
- 假山：一层层的黄石块偏整齐、颜色偏单一，更像“堆”而不是“叠”出来的山；石阶的打磨黄石显得新。
- 水面：倒影和波纹在静止截图里是一块块断开的折线；真机上的动态效果（流动、晃动）需要用户亲眼看。
- 天：薄云纱是静止的，不会动。
- 厅内：木作仍是画面里最大的一块颜色，默认机位橙色色相占 15.8 个百分点（第一轮 30.6）；地面方砖的砖缝在近处偏硬。

- 两盏灯在傍晚的天光下几乎看不出亮；这是按“自然光为主”有意压的，用户可能想要稍亮一点。

### 2.10 精装修一轮（2026-10-10，未经用户视觉验收）

用户看过第二轮以后说：模型做得还可以，但美观度不行，“像毛坯房装修有问题那种”。这一轮只动表面、光和软装，不动空间布局和建筑体量。

Agent 对“毛坯感”来源的判断（推断，供用户核对）：

1. 地面是浅灰、哑光的方砖，0.5 米一道深色灰缝，读起来像水泥地或卫生间地砖。
2. 所有木作都是同一种哑光，家具和建筑木色发橙、发亮，没有漆面和打蜡的光泽。
3. 船篷轩顶是一整片深褐色的壳，椽和板分不出来。
4. 柱子、墙面是空的，没有抱柱联这类“装修完成”的细部；粉墙是一块平整的白板。
5. 交接处（柱脚、椅腿、墙角）缺少接触暗，东西像摆在画面上。
6. 室外青石和方砖每半米一道黑框线，像施工放线。

改了什么：

| 项 | 做法（文件） |
|---|---|

### 3.1 精修零件做了什么（`frontend/src/mc/avatar/`）

- `body.ts`：`elegant`、`petite` 两种体型（`family:'refined'`）和 `oval` 头型；坐姿、座面、靠背、扶手的几何约束与 Q 版相同（`test:mc-avatar` 逐体型逐坐姿检查）。
- `face.ts`：`paintAnimeFace`——72×72 的版式（每 T 两像素），六种表情、三帧说话、眨眼、腮红 / 汗、眼型（round / sharp / droopy / sleepy / sparkle / narrow）与眉型都支持；五官在头上的位置和 Q 版脸一致，眼镜等配件不用改。
- `hair.ts`：`sidelong`、`cloud` 两种发型；`ring`（天使环高光）和 `coil`（卷发折线纹理）只给精修发型用，不改旧发型。
- `build.ts`：精修脸的贴图分配、长风衣在 `elegant` 体型下盖过膝盖、精修长风衣的深 V 领和长翻领、新配件 `belt`。
- `looks.ts`：两人的造型（`basis` / `why` 写明来源和理由）。

### 3.2 已知问题

见第 2.4 节。

### 3.3 以后给其他人物用这套模板（样板认可以后）

1. 体型从 `elegant` / `petite` 选，或按同样的约束新增一种 `family:'refined'` 体型（头缩放 0.58–0.62；跑 `test:mc-avatar` 看坐姿和头身比）。
2. `face.style='anime'`，眼型、眉型、嘴型按外观选，不按性格选。
3. 发型优先在 `hair.ts` 里加新的精修发型（发团要冒出头盒子、轮廓有起伏、刘海一束束有尖梢），不要只换发色。
4. 服装结构用 `outer` / `top` / `bottom` / 配件组合出层次；颜色锚定人物设定。
5. 在 avatar-lab 拍正、侧、背、坐、表情，再进圆桌拍默认机位和 `detail-samplesa` / `detail-samplesb` 这样的近景。
