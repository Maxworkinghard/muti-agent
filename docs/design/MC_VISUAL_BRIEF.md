### R01｜冷夜 / 火光 / 雪与烟（1651.jpeg）
- **[观察]** 暗蓝灰夜色、覆雪的地面与建筑；近处橙红色火焰强烈发光，地面和空中有暖色火星；远处结构部分隐在烟雾/低对比环境中。
- **[候选可借鉴]** 冷环境与局部暖光形成的色温对照；局部光源对附近材质的影响；前后景层次与空气感。
- **[不应自动迁移]** 战斗主题、火灾、强烈黑暗、游戏 HUD、血条、角色手部、字幕。不能推断用户要求把圆桌会议室改成战场或夜景。

### R02｜遮檐下看城市街道（1650.jpeg）
- **[观察]** 前景处于较暗的遮檐内，远处阳光照亮街道；重复的柱子、梁和不同立面向远处汇聚，树木与街道家具丰富中景。
- **[候选可借鉴]** 暗前景框住明亮远景的构图；建筑和树木的纵深关系；有明确朝向的自然光及街景的空间连续性。
- **[不应自动迁移]** 城市街区题材、角色形象、视频字幕与 HUD；也不能以此推断会议室必须采用欧式街区建筑。

### R03｜樱花屋檐 / 湖 / 森林 / 雪山（1652.jpeg）
- **[观察]** 近处木屋檐、垂下的粉色花枝与灯笼构成画框；中景湖面反射岸边的深浅绿色森林；远景山峰带雪，天空清澈明亮。多个距离层次同时可见。
- **[候选可借鉴]** 由建筑向完整自然世界眺望的空间感；前景框景、湖面反射、林线及山体的远近比例；室内/廊下与室外的连通感。
- **[不应自动迁移]** 樱花、雪山、湖面必须同时出现；不能仅用一块远景图片替代所有实际环境层次。

### R04｜野花草甸 / 曲折河流 / 山谷（1654.jpeg）
- **[观察]** 大片高饱和绿草地、密集但不完全均匀的黄色和其他颜色野花；中景有曲折河流，背后山坡、树木、远方天空形成连续地形。
- **[候选可借鉴]** 自然元素的丰富程度、地形起伏、非机械重复的植被分布，以及由小花到河流再到山坡的尺度变化。
- **[不应自动迁移]** 整个圆桌场景都必须采用这一幅图的高饱和色彩；也不等于室内需要塞满花草。

### R05｜雪中建筑 / 黄昏灯光（1653.jpeg）
- **[观察]** 紫灰色暮色和飘雪中有一栋轮廓清晰的建筑，窗/入口透出暖黄光；前景雪面、两侧高树及远处渐弱的清晰度加强距离感。
- **[候选可借鉴]** 建筑自身剪影、局部暖光与冷环境的关系；以树木、气氛和路径引导视线；室内外光线各有角色。
- **[不应自动迁移]** 强制设定为冬季、黄昏或雪景；不能因为画面有电影感就把室内全部压暗。

### R06｜深木色起居空间（IMG_5549.jpeg）
- **[观察]** 深色木墙、木梁和条板地面与浅色墙面形成材料对比；家具包括红色织物沙发、书柜、茶几、地毯、挂画、窗帘与植物；侧窗带入强烈自然光，局部灯具补充暖光。
- **[候选可借鉴]** 有生活痕迹但主体明确的室内细节；木材、布料、地毯、窗光在同一空间中的材质层次；家具不只是功能性方块。
- **[不应自动迁移]** 直接将圆桌会议室做成客厅、摆放沙发或复制原有家具布局；也不能只靠将所有表面刷成深棕色来制造温馨感。

### R07｜花木环绕的木石庭院厨房（IMG_5550.jpeg）
- **[观察]** 木质梁架、木地板和局部石墙形成多层建筑结构；盆栽、垂挂的紫色花串、院落绿意与室内家具穿插；室外日光进入后形成鲜明但细碎的光斑和阴影。
- **[候选可借鉴]** 室内与庭院连续的空间组织；木、石、花叶的材质对照；植物不是简单贴在墙面的重复装饰，而与梁、台面和视线关系相协调。
- **[不应自动迁移]** 厨房水槽、餐厨功能、过量绿植或垂花的固定布局；不能将复杂装饰数量等同于精致度。

### R08｜浅木 / 奶油色 / 织物的温馨客厅（IMG_5548.jpeg）
- **[观察]** 浅木与米白色家具、黄色格纹沙发、花纹墙纸、书架与小物件构成丰富的层次；布料、植物、窗户和暖灯强化日常使用感；画面装饰密度高但有明显的沙发和中心桌。
- **[候选可借鉴]** 浅暖色系与织物图案、软装、墙面陈设的配合；让家具具备细部结构和可辨识的材质，形成有主次的“精致”。
- **[不应自动迁移]** 整体复制客厅陈设、将所有空间做成奶油白或让圆桌主体被道具淹没。

## 3. 跨图片的候选视觉语言（**必须等用户确认**）

这些是从一组内容差异很大的截图中提出的**工作假设**，不是最终设计方案。

1. **空间有真实纵深，而非单层舞台背景。** R02、R03、R04、R05 均有不同距离的物体、遮挡和大气层次。对于圆桌，值得探索从窗框/檐下到近岸、水面、树木、远山的连续空间，但不预先指定必须包含哪些自然元素。
2. **光照是空间塑造手段，不是全屏调色滤镜。** R01、R05 强调冷暖光源反差，R02、R03、R06、R07 则强调有方向的日光、遮挡、投影和明暗过渡。不能简单推断用户希望“全部明亮”或“全部暖黄”；季节和时段尚未定。
3. **室内有家具尺度和材质对比。** R06–R08 的木材、布、石材、玻璃、植物呈现不同视觉角色；桌椅、地板、梁架应有结构层次，而不是同材质的单一方盒。
4. **丰富但有主次。** 室内细节与室外植被都较丰富，但画面仍能找到窗景、主座或家具等视觉中心。圆桌场景需优先保证人物、座椅、议事桌可辨认，再考虑装饰密度。
5. **“Minecraft 方块世界”与高级渲染可以并存。** 图片保留体素/方块造型，同时通过材质、形体组合、光线、反射、植被和空间层次提升品质；不等于要把方块改成照片级现实物件。
6. **色彩没有单一已确认配方。** R01、R05 冷暗，R03、R04 户外鲜亮，R06 深木色，R07 自然暖木，R08 浅奶油色。不能据此自选一个全局色板、强行一键暖化，或宣称用户只喜欢低饱和度。
7. **室内观感与室外世界应分别建模。** 参考图既有外观风景也有家居近景；“窗外壮阔”不意味着会议室室内要占满壮阔景物。

## 4. 圆桌样板下一次视觉对照应观察什么

仅列**观察轴**，不是强制的尺寸参数、性能门槛或已获批设计。

| 观察轴 | 同机位真实渲染中应回答的问题 |
|---|---|
| 场景主次 | 八个人物与圆桌是否是视线中心？门窗、吊灯、花草是否争夺注意力？ |
| 空间可读性 | 室内深度、桌椅活动范围、前后景遮挡是否合理？ |
| 窗外世界 | 能否读出近景、中景、远景，还是一块平面景片？ |
| 光影 | 光从哪里来，投影与结构是否对应？室内阴影是否压得过黑、暖光是否过黄？ |
| 材质 | 地板、桌椅、梁架是否具有区别；木纹、布料、石、叶、水是否仍保持体素风格？ |
| 细节密度 | 有没有“空盒子感”或反过来的“道具堆砌感”？装饰是否支持圆桌交流的主题？ |
| 远近一致性 | 近景高细节与窗外景观是否像处于同一个可探索的世界？ |
| 运行落地 | 截图是否来自真正的 Three.js 场景，而非生成图/概念拼贴？美术模拟是否依赖未经许可的第三方资源？ |

制作方案时，需先说明参考图的哪一部分被借鉴，以及相应的实际场景几何、材质或光照如何实现。不能以增大 Bloom、全局曝光或统一暖色滤镜取代结构、比例与空间问题。

- **真实性与许可**：Minecraft 视频截图的渲染品质可能来自独立 shader、材质包与建筑作者创作；浏览器 Three.js 不可直接运行 Minecraft 的光影包，也不能擅自下载、打包或公开分发无许可素材。
- **不可用完成宣称替代审美评价**：Agent 可验证真实渲染、资源加载和性能，但仅用户可确认视觉方向与最终品质，详见根目录 `AGENTS.md`、`STANDARDS.md`、`VERIFY.md`。
