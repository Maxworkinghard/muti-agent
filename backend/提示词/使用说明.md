# 提示词使用说明

这个文件夹里的 `.md` 文件由 `生成提示词.py` 根据人物 JSON 和性格库自动生成。**不要直接修改这里的文件**，要改就改 JSON，再重新运行生成脚本。

## 文件组成

| 文件 | 内容 | 每次讨论用几个 |
| --- | --- | --- |
| 通用规则.md | 所有人物都要遵守的讨论规则和输出格式 | 1 |
| 角色/理性/*.md | 人物的身份、知识、思想体系和边界，决定从什么角度思考 | 1 |
| 性格/*.md | 性格，决定讨论中的做法和语气 | 1 |

角色没有默认性格。角色只决定知识和看问题的角度；态度和说话方式由用户选的性格决定。同一个角色配上不同的性格，观点来源不变，但说话的人听起来完全不同。

## 组装顺序

一个人物的系统提示词按下面的顺序拼接：

```
通用规则 → 角色 → 性格
```

`组装提示词.py` 会自动完成拼接，并检查所选性格是否存在。任何角色都可以搭配任何性格。

```
python 组装提示词.py 灰先生 --性格 毒舌 --字数 200
python 组装提示词.py 灰先生 --性格 冷幽默 -o 灰先生.md
```

## 调用模型

每个人物单独调用一次模型。system 放组装好的提示词，user 放这一轮的讨论情况：

```
议题：{议题}

参与者：{其他人物的名字和角色，例如 “老苏（追问者）、阿澜（直觉派）”}

发言记录（从开场到现在）：{引擎按顺序放上整场讨论的全部发言；不写摘要，也不截断成最近几条}
{人名}：{发言}
{人名}：{发言}

本轮任务：{例如 “说出你的初始立场和理由” 或 “K 质疑了你的前提，请回应”}
```

模型会返回通用规则里规定的 JSON。只把 `speech` 显示给用户，`respondsTo`、`challenge`、`newPoint` 交给引擎决定下一个发言人和结束时间。
