# 前端对接说明

## 1. 前端要传给后端的参数

| 参数 | 说明 | 例子 |
|---|---|---|
| question | 讨论的问题 | "人有没有自由意志？" |
| members | 参与的人物，2 到 5 人 | 见下 |
| members[].name | 人物名，对应 人物/理性/*.json | "老苏" |
| members[].personality | 性格，1 个，来自 性格库/性格.json | "温和狡猾" |
| rounds | 轮数，最少 2（开场和收尾），默认 3 | 3 |
| maxChars | 每次发言字数上限，默认 150 | 150 |

人物没有默认性格，每个人都必须由用户选定。人物只决定知识面和看问题的角度，态度和语气由性格决定。

前端的下拉选项可以直接读取两个位置：人物/理性/*.json 的 name 和 role 字段、性格库/性格.json。

### 会话编号

`POST /api/discuss` 的响应头 `X-Session-Id` 里是这场讨论的编号，由服务端随机生成；后面的 `/say`、`/pause`、`/resume`、`/stop`、`/ask` 都用它（路径里的 `<会话>`）。

### 用户插话（POST /api/discuss/<会话>/say）

- `{text}`：公开插话——写进公开记录，所有人都能看到，由发言最少的人回应。
- `{text, target}`：点名 = **私聊**——只有被点名的人看得到，不写进公开记录、不算公开发言，他的回应也只回到用户这里。
- 私聊相关的 SSE 事件带 `"private": true`，前端据此给气泡加“私聊”标记。
- 私聊会一直留在被点名那个人的上下文里（`user_message(..., priv=...)`）：他后面公开发言时也带着这段，别人拿不到。
- 讨论结束后点名追问（`/ask` 带 `target`）同理，算私聊。

## 2. 组装系统提示词

    from 组装提示词 import build
    system_prompt = build("老苏", "温和狡猾", max_chars=150)

build 会把 通用规则 + 角色 + 性格 拼成一段系统提示词。人物名或性格名写错时会直接报错。

## 3. 现在的命令行用法

    python 讨论引擎.py "人有没有自由意志？" --人物 老苏:温和狡猾 阿澜:轻快好奇 --轮数 3 --字数 150

加 --试跑 可以只打印发给模型的内容，不调用模型。

## 4. 讨论记录格式（前端展示用）

引擎跑完会写入 讨论记录/时间.json，格式参考 示例/讨论记录示例.json。

- question：问题
- model：使用的模型
- members：[{name, role, personality}]
- rounds、maxChars
- log：发言列表，每条包括：
  - round：第几轮
  - name：发言人
  - speech：发言正文（界面上主要显示这个）
  - respondsTo：回应的是谁
  - stance：立场，取值为 同意 / 部分同意 / 反对 / 提问 / 开场；模型输出无法解析时为 未知
  - newPoint：true 或 false，表示这次有没有提出新观点
  - challenge、challengeTarget：向谁提出的质疑
  - answered：是否回应了别人对自己的质疑
- 以上 log 只放公开内容；点成员的私聊（用户那句话和他的回应）不进 log，也不会出现在总结和判定里，只存在会话内的私聊记录里。
- summary：主持人最后的总结

## 5. 接前端还需要做的改动

讨论引擎.py 现在是命令行程序，用 print 输出、跑完才写文件。接前端时建议：

1. 把 main() 里的流程抽成一个函数，比如 run_discussion(question, members, rounds, max_chars)，每产生一条发言就 yield 一次。
2. 外面套一个 HTTP 接口（如 FastAPI），用 SSE 或 WebSocket 把发言逐条推给前端，一条大约要等几秒。
3. 调用失败时引擎会自动重试 3 次，前端需要显示“等待中”的状态。

## 6. 模型配置

把 模型配置.示例.json 复制一份，改名为 模型配置.json，填上 base_url、model 和 api_key。这个文件只放在服务器上，不要提交到前端代码或代码仓库。

## 7. 维护工具（前端用不到）

- 校验.py：检查人物文件格式是否正确
- 生成提示词.py：修改人物或性格库后，用来重新生成 提示词/ 下的 md 文件
- 人物模板.json：新增人物时照着填
