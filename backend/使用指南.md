# 使用指南

这个包可以让几个 AI 人物围绕一个问题展开讨论。你选人物，再给每个人物挑一个性格，引擎就会让他们轮流发言、互相回应，最后由主持人做总结。

## 一、准备（只做一次）

1. 安装 Python 3.9 或更高版本。引擎只用了 Python 自带的库，不需要 pip install 任何东西。
2. 把 模型配置.示例.json 复制一份，改名为 模型配置.json，填三项：
   - base_url：模型服务地址
   - model：模型名
   - api_key：你的密钥

   只要是兼容 OpenAI 接口的服务都能用，示例文件里列出了 DeepSeek、通义千问、Kimi、OpenAI 和本地 Ollama 的填法。也可以不把 key 写进文件，改为设置环境变量 LLM_API_KEY。

   模型配置.json 里有密钥，不要发给别人，也不要提交到代码仓库。

3. 打开命令行，进入本文件夹：

       cd 人格数据库

## 二、跑一场讨论

    python 讨论引擎.py "数学是被发现的还是被发明的？" --人物 老苏:温和狡猾 K:冷静较真 南姐:毒舌

每个人物的写法是 人物名:性格，中文冒号也可以用。

其他参数：

| 参数 | 作用 | 默认值 |
|---|---|---|
| --轮数 | 讨论几轮，最少 2 轮（开场和收尾） | 3 |
| --字数 | 每次发言的字数上限 | 150 |
| --试跑 | 只打印发给模型的内容，不真的调用模型，不花钱 | 关闭 |

不写问题的话，程序会提示你输入。不写 --人物 会用一组演示搭配：老苏、阿澜、灰先生。

讨论过程会实时显示在命令行里，结束后完整记录保存在 讨论记录/年月日-时分秒.json。记录的格式可以参考 示例/讨论记录示例.json。

## 三、可以选什么

人物决定知道什么、从哪个角度看问题：

| 人物 | 角色 | 看问题的角度 |
|---|---|---|
| 老苏 | 追问者 | 关键词的定义是否清楚 |
| 阿澜 | 直觉派 | 具体例子和图像，推到无穷会怎样 |
| K | 逻辑家 | 论证的每一步是否成立 |
| 灰先生 | 怀疑者 | 我们凭什么知道 |
| 南姐 | 现实派 | 对具体的人有什么影响 |

性格决定讨论时的做法和说话的语气，每人选 1 个：温和狡猾、轻快好奇、冷静较真、冷幽默、直率温暖、老派学究、毒舌、热血。

人物没有默认性格，任何人物都能配任何性格。同一个人物换个性格，看问题的角度不变，说话方式会明显不同。每个性格的具体含义见 性格库/性格.json。

搭配建议：

- 一场 3 到 4 人效果最好，人太多时每人能说的话就少了。
- 让人物之间有反差，比如一个“热血”配一个“毒舌”，讨论会更有来回。
- 同一场里尽量不要让两个人用同一个性格，否则读起来分不清是谁在说。

## 四、讨论是怎么进行的

- 第 1 轮是开场，每个人从自己的角度切入问题，不急着给答案。
- 中间几轮是交锋，引擎会优先让被别人质疑的人先回应，其余的人接着补充或反驳。
- 最后一轮是收尾，每个人说明自己目前的立场，以及哪些地方被说服了。
- 结束后主持人写一份总结：各方观点、达成的共识、还没解决的分歧。

每条发言除了正文，还会标出在回应谁、立场（同意、部分同意、反对、提问、开场）、有没有提出新观点、向谁提出了质疑。

## 五、只想拿提示词，自己调模型

    python 组装提示词.py 老苏 --性格 温和狡猾 --字数 150

这条命令会打印出这个人物的完整系统提示词，加 -o 文件名.md 可以保存到文件。在代码里调用的写法是：

    from 组装提示词 import build
    system_prompt = build("老苏", "温和狡猾", max_chars=150)

## 六、增加或修改人物

1. 照着 人物模板.json 填一个新文件，放进 人物/理性/。
2. 运行 python 校验.py，检查格式是否正确。
3. 运行 python 生成提示词.py，重新生成 提示词/ 下的文件。

修改性格库或已有人物之后，也要运行第 3 步。

## 七、常见问题

- 提示“找不到 模型配置.json”：还没有完成第一部分的第 2 步。
- 提示“还没有填写 api_key”：模型配置.json 里的 key 还是示例文字。
- 提示“调用失败，稍后重试”：网络或模型服务出了问题，引擎会自动重试 3 次。如果一直失败，检查 base_url、model 和 key 是否正确。
- 提示人物或性格不存在：名字写错了，对照第三部分的列表检查。
- 中文显示乱码：Windows 上改用 python -X utf8 讨论引擎.py ... 来运行。
