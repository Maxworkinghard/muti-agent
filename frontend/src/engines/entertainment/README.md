# 娱乐引擎（活人群聊）

像宿舍里几个人真的在聊天：没有轮次，也没人安排谁说话。每个人听完一句话都会起反应——火气、委屈、开心、无聊会攒、会上头、会冷下来——谁被戳到了、憋不住了谁就开口，说到一半可能被人插嘴，没人想说就冷场、散场。你可以随时插话、点名，或者私下撺掇某个人。

引擎跑在浏览器里，底盘在 `../live/`（所有“活人聊天”类模式共用），这里只放娱乐模式自己的玩法：

| 文件 | 内容 |
| --- | --- |
| `index.ts` | 引擎包：`createLiveEngine(createEntertainmentKit())` |
| `kit.ts` | 四种情绪（`MOODS`）、从人物文件读性情（`readTemperament`）、组装提示词和总结 |
| `prompt.ts` | 提示词：统一规则、人物协议、性情、闲聊规则、输出格式；总结 |
| `material.ts` | 事实和安全规则，热梗卡 |
| `config.ts` | 可调参数：温度、`maxMessages`（一场最多几次发言，默认 50）、`pace`（节奏倍数，默认 1）、梗卡 |

人物在 `frontend/personas/entertainment/`，7 个：老方（反驳型）、小正（反反驳型）、阿实（确实型）、小林（正常人）、阿冷、小戏、阿禾。每人的性情写在 `x-temperament` 里（说明见 `frontend/personas/README.md`）。

## 1. 流程

没有轮次。你的第一句话就是开场，之后一直循环：

1. 有人说了一段话（一到三条短消息），所有人**同时**各自“听”一遍：每人一次模型调用，用自己完整的人设，给出心里话、情绪变化、对谁的好恶变化、多想开口（0～10）、想说什么、要不要插嘴。
2. 情绪的账由代码记：模型只判断“这句多扎心”，涨多少按性情放大（脾气放大火气、玻璃心放大委屈），每过一次发言往平时状态回落（记仇的人回落得慢），无聊会随着聊天自己慢慢涨。
3. 按开口冲动挑人（见下一节），他开口，回到第 1 步。

话题会漂：有人把话题岔开时，工作区会出现一条「换话题 · xxx」的分隔。

## 2. 谁先说

不写死顺序，也不按人物 id 写规则：

- **开口冲动** = 模型给的想说程度 + 话痨程度 + 被你点名（+3）+ 憋久了没说（+1）− 刚说过（−2）+ 一点随机。过了门槛（话痨门槛低）才会开口。
- **多快张嘴**：越想说、越上头反应越快，要说的话越长组织得越久，嘴快的人快。最快的那个先说；你点了名的人优先回你。
- **抢话**：第二个人几乎同时准备好、又很想说，就一起开口——他的话是没听到第一个人就说出来的。
- **插嘴**：话一想好就写进记录，大家从这一刻开始边听边想，所以说到一半就可能有人憋不住。够上头、够想说、性子够急（脾气、话痨）才会插嘴；模型会指出“听到哪几个字就忍不住了”，就在那里截断，被打断的人会恼火、对插嘴的人好感下降，下一轮还记着没说完的话。每三次发言最多一次插嘴。
- **小声**：不抢话的小反应（“哈哈哈哈”“？”），在下一个人开口前冒出来。
- **冷场**：谁都不想说就等一会儿，让大家再想一轮（刚说完的人也想）；还是没人接就散场。
- 你说了话一定有人接：没人够格时让最想说的那个开口。

## 3. 每个人能看到什么

- 公开聊天记录（最近 60 条，带编号、谁回谁、谁被打断、谁小声说了什么）。
- 只有自己和你知道的私聊。
- 自己的状态：心情（四种情绪的强度和说法）、对谁有意见、对话题的态度和能拿出来说的私货、正在打算干嘛、上一刻的心里话、想说还没说出口的话、刚才被谁打断了、多久没开口了。
- 这一刻发生了什么：谁刚开口（还没说完）、你点名问他了、冷场了、快散场了、谁一直没吭声。

看不到别人的人设和别人的心里话。

## 4. 人物怎么体现

system 提示词：开场说明、统一运行规则（事实和安全，优先于人设）、人物协议 `persona` 原文（去掉展示、版本和性情参数）、性情翻成的话（“脾气急，火气来得快；特别要面子，很难当场认输”）、在场的人、话题、梗卡、闲聊规则、输出格式。

闲聊规则要求：像群聊一样短，想说的多就拆成几条；情绪决定怎么说（上头短句连发、委屈嘴硬或不吭声、开心话多、无聊敷衍或岔开）；不为了客气附和，改口要找台阶；用户是群友不是裁判，可以不同意他。

提示词按“记录 → 私聊 → 状态 → 现在”排，system 部分每次都一样，模型服务的前缀缓存能省掉大部分重复。

## 5. 你怎么插手

- **对全体说**：写进公开记录，所有人对你的话起反应；你被当成群里的一个朋友，怼了谁谁照样不爽。暂停中说话会自动接着聊。
- **@点名**：`@老方 你自己不也天天刷？` 或者用名字开头（`老方，……`），被点的人优先回你。
- **私聊**（点成员再说话）：只有他知道。它会改他的内心——情绪、对某人的看法、态度、打算——他会私下回你一句，之后按自己的方式照着这个方向走（不会一下子翻脸，也不会说漏是你让他这么做的）。比如“老方刚才在笑你”是拱火，“别吵了”是灭火。
- **打字就暂停**：一开始打字大家就停下来等你（顶部显示「✎ 等你说完」），发出去或者把字删光就接着聊；点「继续」则不等。
- **看内心**：点成员，工作区上方显示他的情绪条、态度、打算、心里话、对谁有意见、你对他说过的话。场景里的小人会换表情，头上挂着心情。

## 6. 结束与总结

到 `maxMessages` 次发言，或者冷场两次，就散场；记录员（温度 0.3）读完整记录，写一句“这场聊下来”（谁跟谁杠上了、谁被说服了、名场面）和共识 / 分歧 / 没聊完 / 可以接着聊。散场后你再开口，大家能接着聊一阵。

## 7. 异常处理

- **停止**（离开页面）：中断所有进行中的请求，不当成错误显示。
- **某个人的反应出错或没按格式回答**：重试一次，还不行这一轮就当他没反应，其他人照常聊。
- **所有人都没反应过来**（模型连不上、Key 不对）：停下来，工作区显示错误和「重试」；你再开口也会接着来。
- **私聊没接住**：显示错误，点重试重新回你。
- **总结出错**：显示错误，可以重试。

## 调参数

`npm run sim`（在 `frontend/` 下）不开浏览器跑一场，逐句打印，最后给统计（每人几句、插嘴、打断、小声、调用次数和耗时）：

```bash
npm run sim -- --topic "假如一周没有手机，你会怎么办？" --cast 老方,小正,小林,阿冷,阿禾 --minds \
  --whisper "5:小林:老方刚才在笑你" --say "10:@老方 你自己不也天天刷？"
```

常调的地方：人物的 `x-temperament`；`config.ts` 的 `pace`、`maxMessages`、`temperature`；`kit.ts` 的情绪档位和回落速度；`../live/engine.ts` 顶部的等待时间、说话速度，`pick()` 里的开口门槛，`considerInterrupt()` 里的插嘴门槛。

用思考型模型会明显变慢（每个人每次都要先想），想要来回快、插嘴多，用不带思考的快模型（如 `deepseek-chat`）。
