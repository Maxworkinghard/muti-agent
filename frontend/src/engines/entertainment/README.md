# 娱乐引擎（导演 + 演员）

像宿舍里几个人真的在聊天，但整场有一个导演在看着：下一句谁说、冲谁说、带什么情绪，每个人的情绪怎么一步步递进、说话状态怎么变，全场往哪走（升温、爆发、冷却、跑题、收尾），都由导演根据大家实际说出口的话来定。台词不由导演写，由每个角色按自己的人设说。你可以随时暂停、插话、点名，或者私下撺掇某个人。

三层各管各的：

| 层 | 做什么 | 在哪 |
| --- | --- | --- |
| 引擎 | 记账（情绪、说话状态、态度、打算、好恶）、限速、执行导演的安排、暂停 / 插话 / 私聊、流水线、结束和总结 | `../live/engine.ts`、`../live/mind.ts` |
| 导演 | 每一句一次调用：看全场和每个人的账，排下一步 | 提示词在 `prompt.ts` 的 `buildDirectorMessages` |
| 演员 | 每一句一次调用：拿着自己的人设和导演的提示，用自己的话说出来；也负责私下回你 | `prompt.ts` 的 `buildActorMessages` |

| 文件 | 内容 |
| --- | --- |
| `index.ts` | 引擎包：`createLiveEngine(createEntertainmentKit())` |
| `kit.ts` | 四种情绪（`MOODS`）、从人物文件读性情（`readTemperament`）、组装导演和演员的提示词、总结 |
| `prompt.ts` | 导演：阵容、导演规则、输出格式；演员：统一规则、人物协议、性情、闲聊规则；总结 |
| `material.ts` | 事实和安全规则，热梗卡 |
| `config.ts` | 可调参数：演员和导演的温度、`maxMessages`（一场最多几次发言，默认 50）、`pace`（节奏倍数，默认 1）、梗卡 |

人物在 `frontend/personas/entertainment/`，7 个：老方（反驳型）、小正（反反驳型）、阿实（确实型）、小林（正常人）、阿冷、小戏、阿禾。每人的性情写在 `x-temperament` 里（说明见 `frontend/personas/README.md`）。

## 1. 一句话是怎么来的

1. **导演排这一步**，输出：
   - 下一句谁说、冲谁说（某人、你，或者不冲谁）、大意（不是台词）、他说这句时的情绪、接的是哪条；
   - 这一步谁的情绪变了多少（每人每种情绪 −2～2）、谁的说话状态变成什么（比如“句子变短，开始翻旧账”）、谁的态度 / 打算 / 对谁的好感变了；
   - 全场走到哪（升温、爆发……）和接下来几步的打算（比如“再吵一个来回，让阿禾打圆场”）；
   - 旁人顺口的小反应（“哈哈哈”“？”）、要不要插嘴、要不要换话题、要不要散场。
2. **演员说出来**：这个角色拿着自己的人设、导演给的提示（冲谁、大意、情绪、说话状态）、自己能看到的记录和私聊，说出一到三条短消息。大意可以变通，腔调是他自己的。
3. **引擎记账、显示**：照导演的安排记账（限速：每步情绪最多变 3），这句一个字一个字显示出来。
4. **流水线**：这句话一出口，下一句就开始准备（导演看到的是刚说出口的原话），所以说完一句，下一句基本已经备好。

导演看的是角色实际说出口的话，不是自己给的大意；角色说偏了，导演就按实际的调整后面的安排。

## 2. 情绪和说话状态怎么递进

- **账由引擎记，每次都喂回给导演和演员**，所以聊长了也不会忘了谁在生气、谁被冷落、谁已经变了调。
- **情绪**：导演每步给变化量，引擎按性情放大（脾气放大火气、玻璃心放大委屈），再限速；每过一次发言往平时状态回落，记仇的人回落得慢；无聊会随着聊天自己慢慢涨。
- **说话状态**：导演改了就一直带着，直到导演再改。上头了句子变短、翻旧账；没面子了嘴硬、阴阳怪气；开心了话多、爱接梗；无聊了敷衍、岔话题。
- **人设底线**：状态可以变，人不能变——口头禅和核心习惯不变（阿实再生气开口也还是“确实”）。导演和演员的提示词里都写了这条。
- **全场的线**：导演自己定升温、爆发、冷却，不让一直吵，也不让一直和气、很快全体同意。导演只在幕后，网页上看不到它的安排，只看得到大家聊天和各自的心情；换话题时工作区会出现一条分隔。

## 3. 插嘴、小反应、冷场

- **插嘴**：一句话正在说的时候，下一句已经在排；导演如果安排有人插嘴，会给出“对方原话里让他忍不住的那几个字”，说到那里就停住、截断，插嘴的人马上接（他的话还没组织好，说话的人会在那里停一下，最多等 4 秒）。被打断的人会恼火、对插嘴的人好感下降，还记着没说完的话。每三次发言最多一次插嘴。
- **小反应**：导演安排的“哈哈哈”“？”在下一句开口前冒出来，不占发言。
- **冷场**：导演觉得没人有话说时就空一步；连着两次冷场就散场。

## 4. 每个角色能看到什么

公开聊天记录（最近 60 条，带编号、谁回谁、谁被打断、谁小声说了什么）、只有自己和你知道的私聊、自己的账（心情、说话状态、态度、打算、对谁有意见、上一刻的心里话、刚才被谁打断）、导演给这一句的提示。看不到别人的人设、别人的账和导演的全盘安排。

导演看得到所有人的账和你的私聊，但只能通过被私聊的那个人来体现，不能让别人知道。

## 5. 你怎么插手

- **对全体说**：写进公开记录，导演这一步必须安排人接你；你被当成群里的一个朋友，可以有人不同意你。
- **@点名**：`@老方 你自己不也天天刷？` 或者用名字开头（`老方，……`），导演会让被点的人先接。
- **私聊**（点成员再说话）：他自己私下回你一句，情绪和打算跟着变；导演也知道了，还没说出口的下一句会重新排，之后这个人会按自己的方式照着这个方向走（不会一下子翻脸，也不会说漏是你让他这么做的）。
- **暂停 / 继续**：只由底部的按钮控制。点「⏸ 暂停」，正在说的人说完这一条就停；暂停期间你对全体说的话记下了，点「▶ 继续」后导演会安排人接；私聊照样马上私下回你。
- **看内心**：点成员，工作区上方显示他的情绪条、说话状态、态度、打算、心里话、对谁有意见、你对他说过的话。场景里的小人会换表情，头上挂着心情。

## 6. 结束与总结

到 `maxMessages` 次发言、导演说该散了（至少聊过 8 次）、或者连着冷场两次，就散场；记录员（温度 0.3）读完整记录，写一句“这场聊下来”（谁跟谁杠上了、谁被说服了、名场面）和共识 / 分歧 / 没聊完 / 可以接着聊。散场后你再开口，大家能接着聊一阵。

## 7. 异常处理

- **停止**（离开页面）：中断所有进行中的请求，不当成错误显示。
- **导演或演员没按格式回答**：再问一次；还不行，整步自动重试一次；再失败就停下来，工作区显示错误和「重试」，你再开口也会接着来。
- **私聊没接住**：显示错误，点重试重新回你。
- **总结出错**：显示错误，可以重试。

## 调参数

`npm run sim`（在 `frontend/` 下）不开浏览器跑一场，逐句打印；调参用，所以导演每一步的安排（全场走到哪、打算、下一句谁说）和说话状态的变化也会打出来（只在命令行里，网页上不显示），最后给统计：

```bash
npm run sim -- --topic "假如一周没有手机，你会怎么办？" --cast 老方,小正,小林,阿冷,阿禾 --minds \
  --whisper "5:小林:老方刚才在笑你" --say "10:@老方 你自己不也天天刷？"
```

常调的地方：`prompt.ts` 的导演规则（`DIRECTOR_RULES`）和闲聊规则；人物的 `x-temperament`；`config.ts` 的 `pace`、`maxMessages`、`temperature`、`directorTemperature`；`../live/engine.ts` 顶部的限速（`STEP_MOOD`）、说话速度（`CPS`）、插嘴最多等多久（`MAX_CUT_WAIT`）。

每句要调两次模型（导演一次、演员一次），用思考型模型会明显变慢；想要节奏快、插嘴能插上，用不带思考的快模型（如 `deepseek-chat`）。
