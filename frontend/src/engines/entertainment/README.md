# 娱乐引擎（导演 + 演员）

像宿舍里几个人真的在聊天。整场有一个导演看着节奏：每一步提名可能接话的人、给个话头，把握情绪怎么递进、说话状态怎么变、全场往哪走（升温、爆发、冷却、跑题、收尾）。但导演不是说了算的那个：谁真的开口，看现场各人有多憋不住；怎么说、心里怎么想，由每个角色按自己的人设定，导演的话头不合人设可以不接。所以同样的开头，每场都可能聊成不一样的样子。你可以随时暂停、插话、点名，或者私下撺掇某个人。

三层各管各的（为什么这么分，见 `../live/README.md`）：

| 层 | 做什么 | 在哪 |
| --- | --- | --- |
| 引擎 | 按各人此刻的冲动从导演的候选里抽谁开口；记账（情绪、说话状态、看法、打算、好恶）、限速、暂停 / 插话 / 私聊、流水线、结束和总结 | `../live/engine.ts`、`../live/mind.ts` |
| 导演 | 每一步一次调用：看全场和每个人的账，提名 1~3 个可能接话的人和话头，管节奏 | 提示词在 `prompt.ts` 的 `buildDirectorMessages` |
| 演员 | 每一句一次调用：拿着自己的人设和导演的建议，自己决定怎么说；自己报看法、打算和心情；也负责私下回你 | `prompt.ts` 的 `buildActorMessages` |

| 文件 | 内容 |
| --- | --- |
| `index.ts` | 引擎包：`createLiveEngine(createEntertainmentKit())` |
| `kit.ts` | 四种情绪（`MOODS`）、从人物文件读性情（`readTemperament`）、组装导演和演员的提示词、总结 |
| `prompt.ts` | 导演：阵容、导演规则、输出格式；演员：统一规则、人物协议、性情、闲聊规则；总结 |
| `material.ts` | 事实和安全规则，热梗卡 |
| `config.ts` | 可调参数：演员和导演的温度、`maxMessages`（一场最多几次发言，默认 50）、`pace`（节奏倍数，默认 1）、`spontaneity`（随性程度，默认 0.6）、梗卡 |

人物在 `frontend/personas/entertainment/`，7 个：老方（反驳型）、小正（反反驳型）、阿实（确实型）、小林（正常人）、阿冷、小戏、阿禾。每人的性情写在 `x-temperament` 里，会的小反应写在 `x-reactions` 里（说明见 `frontend/personas/README.md`）。

## 1. 一句话是怎么来的

1. **导演提名**，输出：
   - 这一步可能接话的 1~3 个人（最想让谁说排第一），每人带冲谁说（某人、你，或者不冲谁）、话头（不是台词）、建议的情绪、接的是哪条、要不要插嘴；
   - 到这一步为止旁人的情绪变了多少（每人每种情绪 −2～2）、谁的说话状态变成什么（比如“句子变短，开始翻旧账”）、谁对谁的好感变了；
   - 全场走到哪（升温、爆发……）和接下来几步的打算（比如“再吵一个来回，让阿禾打圆场”）；
   - 旁人顺口的小反应（谁、哪一种）、要不要换话题、要不要散场。
2. **现场抽签**：引擎给每个候选算此刻的冲动（话多不多、情绪多热、是不是冲他来的、看不看得惯刚说话的人、刚说完没有、憋了多久），按随性程度 `spontaneity`（默认 0.6）的概率按冲动抽一个，否则用导演首选。你点名的人一定先接；你说了话，只在冲你说的候选里抽。
3. **演员说出来**：这个角色拿着自己的人设、导演的建议（冲谁、话头、情绪、说话状态）、自己能看到的记录和私聊，说出一到三条短消息。建议不合人设就不照着来，并说一句为什么（导演下一步能看到）；说完自己报对这事的看法、接下来的打算、心情的变化。
4. **引擎记账、显示**：旁人的情绪照导演的估计、说话的人的照他自己报的，都限速（每步最多变 3）；这句一个字一个字显示出来。
5. **流水线**：这句话一出口，下一句就开始准备（导演看到的是刚说出口的原话），所以说完一句，下一句基本已经备好。

导演看的是角色实际说出口的话，不是自己给的话头；角色没照着说，导演就按实际的调整后面的安排。

## 2. 情绪和说话状态怎么递进

- **账由引擎记，每次都喂回给导演和演员**，所以聊长了也不会忘了谁在生气、谁被冷落、谁已经变了调。
- **情绪**：导演每步给变化量，引擎按性情放大（脾气放大火气、玻璃心放大委屈），再限速；每过一次发言往平时状态回落，记仇的人回落得慢；无聊会随着聊天自己慢慢涨。
- **说话状态**：导演改了会带几次发言，过 6 次发言自动回到这个人平时的样子（导演再写一次就续上），免得一次判断长期锁住一个人。上头了句子变短、翻旧账；没面子了嘴硬、阴阳怪气；开心了话多、爱接梗；无聊了敷衍、岔话题。
- **性格是倾向，不是逐句任务**：老方、小正爱找茬，但反对通常从具体话语里听得出来，不必每句喊口号；阿实也不必每次都说“确实”。人物可以因面子、好处、关系或情绪暂时装作赞同、收住本来想说的话，甚至说出与平常相反的话；真实看法和打算由演员自己记（导演只能看），内心想法保留嘴上与心里的落差。变化要接得上当下情境，不随机变成另一个人。
- **全场的线**：导演自己定升温、爆发、冷却，不让一直吵，也不让一直和气、很快全体同意。导演只在幕后，网页上看不到它的安排，只看得到大家聊天和各自的心情；换话题时工作区会出现一条分隔。

## 3. 插嘴、小反应、冷场

- **插嘴**：一句话正在说的时候，下一句已经在排；导演如果提名有人插嘴（并且抽中了他），会给出“对方原话里让他忍不住的那几个字”，说到那里就停住、截断，插嘴的人马上接（他的话还没组织好，说话的人会在那里停一下，最多等 4 秒）。被打断的人会恼火、对插嘴的人好感下降，还记着没说完的话，下一步也更想接话。每三次发言最多一次插嘴。
- **小反应**：导演只定谁、哪一种（笑、惊讶、附和、不服、疑问、心疼、敷衍），说什么从这个人自己的小反应里挑（不重复最近用过的），在下一句开口前冒出来，不占发言；他不会的那种反应就不出声，比如小林不会“心疼”。
- **冷场**：导演觉得没人有话说时就空一步；连着两次冷场就散场。

## 4. 每个角色能看到什么

公开聊天记录（最近 60 条，带编号、谁回谁、谁被打断、谁小声说了什么）、只有自己和你知道的私聊、自己的账（心情、说话状态、态度、打算、对谁有意见、上一刻的心里话、刚才被谁打断）、导演给这一句的提示。看不到别人的人设、别人的账和导演的全盘安排。

导演看得到所有人的账和你的私聊，但只能通过被私聊的那个人来体现，不能让别人知道。

## 5. 你怎么插手

- **对全体说**：写进公开记录，导演这一步必须安排人接你；你被当成群里的一个朋友，可以有人不同意你。
- **@点名**：`@老方 你自己不也天天刷？` 或者用名字开头（`老方，……`），被点的人一定先接（导演没提名他也一样）。
- **私聊**（点成员再说话）：他自己私下回你一句，情绪和打算跟着变；导演也知道了，还没说出口的下一句会重新排，之后这个人会按自己的方式照着这个方向走（不会一下子翻脸，也不会说漏是你让他这么做的）。
- **暂停 / 继续**：只由底部的按钮控制。点「⏸ 暂停」，正在说的人说完这一条就停；暂停期间你对全体说的话记下了，点「▶ 继续」后导演会安排人接；私聊照样马上私下回你。
- **看内心**：点成员，工作区上方显示他的情绪条、说话状态、态度、打算、心里话、对谁有意见、你对他说过的话。场景里的小人会换表情，头上挂着心情。

## 6. 结束与总结

到 `maxMessages` 次发言、导演说该散了（至少聊过 8 次）、或者连着冷场两次，就散场；记录员（温度 0.3）读完整记录，写一句“这场聊下来”（谁跟谁杠上了、谁被说服了、名场面）和共识 / 分歧 / 没聊完 / 可以接着聊。散场后你再开口，大家能接着聊一阵。

## 7. 异常处理

- **停止**（离开页面）：中断所有进行中的请求，不当成错误显示。
- **导演或演员没按格式回答**：再问一次；还不行，整步自动重试一次；再失败就停下来，工作区显示错误和「重试」，你再开口也会接着来。
- **私聊没接住**：显示错误，点重试重新回你。
- **总结出错**：显示错误，可以重试。

## 调参数

`npm run sim`（在 `frontend/` 下）不开浏览器跑一场，逐句打印；调参用，所以导演每一步提名了谁、各人冲动多大、抽中了谁（导演首选还是按冲动抽中）、演员没照导演说的理由、说话状态和看法的变化也会打出来（只在命令行里，网页上不显示），最后给统计：

```bash
npm run sim -- --topic "假如一周没有手机，你会怎么办？" --cast 老方,小正,小林,阿冷,阿禾 --minds \
  --whisper "5:小林:老方刚才在笑你" --say "10:@老方 你自己不也天天刷？"
```

`--runs 3` 同一设置连跑 3 场，比较开场是谁、发言顺序差多少、各人口吻重合多少、导演首选被抽中的比例、演员没照导演说的比例；`--spontaneity 0.3` 临时换随性程度。

常调的地方：`prompt.ts` 的导演规则（`DIRECTOR_RULES`）和闲聊规则；人物的 `x-temperament`、`x-reactions`；`config.ts` 的 `spontaneity`、`pace`、`maxMessages`、`temperature`、`directorTemperature`；`../live/engine.ts` 里的冲动怎么算（`impulse`）、限速（`STEP_MOOD`）、说话状态多久过期（`STYLE_TTL`）、说话速度（`CPS`）、插嘴最多等多久（`MAX_CUT_WAIT`）。

每句要调两次模型（导演一次、演员一次），用思考型模型会明显变慢；想要节奏快、插嘴能插上，用不带思考的快模型（如 `deepseek-chat`）。
