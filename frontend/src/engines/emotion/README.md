# 情感分析引擎（导演 + 演员）

你带着一件让自己心里不好受的事来，七种回应风格（直言的芥末、讨好的好好、理智的冷萃、只说“确实”的复读机、倾听的树洞、暖心的暖宝宝、暴躁的炮仗）围坐着一起接住它。和娱乐模式用同一套底盘（`../live/`）：一个导演看着整场，排下一句谁说、冲谁说、带什么情绪，每个人的情绪怎么递进、说话状态怎么变，整场走到哪一步；台词不由导演写，由每个角色按自己的人设说。

三层各管各的：

| 层 | 做什么 | 在哪 |
| --- | --- | --- |
| 引擎 | 记账（情绪、说话状态、态度、打算、好恶）、限速、执行导演的安排、分步、暂停 / 插话 / 私聊、流水线、结束和总结 | `../live/engine.ts`、`../live/mind.ts` |
| 导演 | 每一句一次调用：看全场和每个人的账，排下一步 | `prompt.ts` 的 `buildDirectorMessages` |
| 演员 | 每一句一次调用：拿着自己的人设和导演的提示，用自己的话说出来；也负责私下回你 | `prompt.ts` 的 `buildActorMessages` |

| 文件 | 内容 |
| --- | --- |
| `index.ts` | 引擎包：`createLiveEngine(createEmotionKit())` |
| `kit.ts` | 四种情绪（`MOODS`）、三步（`STAGES`，取自 `data/modes.ts` 的轮次名）、从人物文件读性情（`readTemperament`） |
| `prompt.ts` | 导演：阵容、三步的目标、导演规则、输出格式；演员：统一的事实和安全规则、人物配置、性情、聊天规则；总结 |
| `config.ts` | 可调参数：演员和导演的温度、`maxMessages`（一场最多几次发言，默认 30）、`pace`（节奏倍数，默认 1） |

人物在 `frontend/personas/emotion/`，每人的性情写在 `x-temperament` 里（说明见 `frontend/personas/README.md`）。

## 1. 讨论流程：三步

步骤名和前端的轮次名一致，工作区按步骤分段：

1. **回应情绪**：先接住这件事里最难受的情绪，让你觉得被听见；可以试探着猜、允许你纠正，不急着讲道理、给办法。
2. **分清事实与感受**：把发生了什么、你的感受、你对别人意图的解释或猜测、还不知道的部分分开；不同回应风格在这里最容易有分歧，导演会让它们碰一碰（冷静的人拆掉着急的人的夸大，直说的人点破打圆场的人的回避）。
3. **下一步行动**：落到一到三个现在就能做的小步子（说什么、做什么、先确认什么），具体、小、做得到，由你自己选。

每一步走多久由导演看现场定（一般三到六次发言，你还沉在情绪里就在第一步多待一会儿）。导演在 `arc` 里写现在在哪一步，底盘只往前走、不回头；导演看到的“走到哪了”会写成第几步、这一步已经说了几次。

## 2. 发言顺序

没有固定轮次，也不是七个人轮流说：谁被触动谁接，同一个人别连着说太多次，一直没吭声的人适时被拉出来。开场第一句由随机抽中的人接你的话（相同阵容连续两场不会同一个人开头），切入点也随机（`data/conversationVariation.ts`）。

- **流水线**：一句话一出口，下一句就开始准备，所以说完一句，下一句基本已经备好。
- **插嘴**：只在有人说得太过（夸大、指责过头、乱下结论）时用，说到让人忍不住的那几个字就截断；「回应情绪」这一步尽量不插嘴。
- **小反应**：“确实”“抱抱”“嗯嗯”这类顺口的反应，不占发言。

## 3. 每个人能看到什么

- **演员**：公开对话记录（最近 60 条，带编号、谁回谁、谁被打断）、只有自己和你知道的私聊、自己的账（心情、说话状态、态度、打算、对谁有意见、上一刻的心里话）、导演给这一句的提示。看不到别人的人设、别人的账和导演的全盘安排。
- **导演**：所有人的账和你的私聊，但私聊只能通过被私聊的那个人来体现，不能让别人知道。

## 4. 人物怎么体现

- **人设**：身份、知识、思考方式、价值观、回应风格（行为、表达风格、口头禅）、底线原样交给演员；口头禅偶尔自然冒出来即可，不是每句都要说。
- **性情**：`x-temperament` 决定同一句话在他身上激起多大情绪——脾气放大火气，心软放大心疼，记仇的人火气消得慢；性情也翻成话告诉导演和演员（“急脾气，一听到不公平的事就冒火”）。
- **四种情绪**（都是在座的人自己的情绪）：

  | 情绪 | 什么时候涨 | 表情 |
  | --- | --- | --- |
  | 心疼 🥺 | 你说出难受的细节（心软的人涨得多） | 脸红 |
  | 火气 😤 | 听到对方做得过分、被别人说得太冲（脾气急的人涨得多，火气高的人爱插嘴） | 皱眉 |
  | 担心 😟 | 你流露出很糟或危险的状态 | 冒汗 |
  | 欣慰 😌 | 你说好受一点了、愿意试试了 | 笑眼 |

  导演每步给变化量（每人每种最多 ±2），引擎按性情放大、限速（每步最多变 3），每过一次发言往平时的状态回落。
- **说话状态**：心疼时语气放软、话变少；火气上来句子变短、带感叹；担心时问得更细；欣慰时轻松一点。导演改了就一直带着。
- **统一规则优先于人设**：只根据你说过的和记录里的内容说话，猜测说成猜测；不下诊断、不贴标签、不给医学法律投资建议；不怂恿报复或伤害；你流露自伤、轻生、伤害别人、被虐待等危险信号时，全场收起玩笑、指责和敷衍，认真回应，鼓励联系身边可信任的人、专业机构或当地紧急服务。

## 5. 你怎么插手

- **对全体说**：导演这一步必须安排人接你；你是当事人，不是主持人也不是裁判。
- **@点名**：`@冷萃 你觉得他是故意的吗？` 或者用名字开头（`冷萃，……`），被点的人先接。
- **回答大家的问题**：有人问了你一个具体的问题后，最多再有一个人从别的角度补一句，然后导演让全场停下来等你回答（成员显示“等你开口”）：这期间不再调用模型，也不会收尾；你一开口就接着聊，点「⏸ 暂停」再点「▶ 继续」也会接着聊。
- **私聊**（点成员再说话）：他私下回你一句，情绪和打算跟着变，之后按自己的方式照这个方向走（比如你私下让炮仗收着点，他之后会收着说），不会说漏是你让他这么做的。
- **暂停 / 继续**：只由底部按钮控制；暂停期间你对全体说的话记下了，点继续后导演会安排人接，私聊照样马上回。
- **看内心**：点成员，工作区上方显示他的情绪条、说话状态、对这件事的态度、打算、心里话、对谁有意见。

## 6. 结束与结论

走到「下一步行动」、给出了一到三个具体的小步子、你的事基本被接住了，导演写 `end`，至少聊过 8 次发言才收尾；**没走到最后一步时导演提前说 end 不算数**。走到最后一步后连着冷场两次也收尾；到了 `maxMessages` 次发言无论走到哪都收尾。

收尾时记录员（温度 0.3）读完整的公开记录（不含私聊），写一段“这场聊下来”（你这件事里最主要的情绪、可能在意的是什么、大家帮你看清了什么），以及共识、分歧（哪两种风格怎么看）、待验证（还需要你确认的事实）、建议（一到三个小步子）。收尾后你再开口，大家能接着聊一阵。

## 7. 异常处理

- **停止**（离开页面）：中断所有进行中的请求，不当成错误显示。
- **导演或演员没按格式回答**：再问一次；还不行，整步自动重试一次；再失败就停下来，工作区显示错误和「重试」，你再开口也会接着来。
- **私聊没接住**：显示错误，点重试重新回你。
- **总结出错**：显示错误，可以重试。

## 调参数

`npm run sim -- --mode emotion`（在 `frontend/` 下）不开浏览器跑一场，逐句打印导演的安排、走到哪一步、说话状态的变化，最后给统计；大家停下来等你开口时，用 `--reply` 替你说一句（默认“嗯，你们接着说吧”）：

```bash
npm run sim -- --mode emotion --topic "朋友答应周五回复，到现在还没消息" --cast 冷萃,树洞,暖宝宝,炮仗,芥末 --minds \
  --reply "我也不确定他是不是忘了" --whisper "4:炮仗:你说话收着点"
```

`npm run test:emotion` 用假模型检查三步分段、没走完不收尾、冷场等你开口、私聊和收尾，不花钱。

常调的地方：`prompt.ts` 的导演规则和三步的目标（`STAGE_GOALS`）、聊天规则；人物的 `x-temperament`；`config.ts` 的 `maxMessages`、`temperature`、`directorTemperature`、`pace`。

每句要调两次模型（导演一次、演员一次），用思考型模型会明显变慢。
