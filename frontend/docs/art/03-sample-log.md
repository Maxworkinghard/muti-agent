> 规矩：每一轮先把真实截图里看到的差距写在这里，再动手改；改完拍下一轮，对照这里逐条核对。

> 拍摄条件：Windows 上的无头 Chrome + swiftshader 软件渲染，1440×960，画质档“高”。只能看静态画面：GPU 阴影的细节、帧率、各画质档的差别都验证不了。
> 基线：`baseline/`（e460400，旧 Q 版之前的方块人 + 旧椅子 + 方块地面）。`sample/wip-r0/` 是上一位接手人的开发截图，不算正式轮次。

## 开工前（83e9356）的状态

- `npx tsc --noEmit`、8 个 `test:mc-*` 全部通过（本机重跑确认）。
- 实验台重拍（`.shots/chk0`）：上一位改过的头发还是竖条纹木箱的样子，侧面一圈“高光环”读成一排虚线；坐姿脚离地 0.31 米、踩在脚踏上。
- **发现一个硬冲突**：旧 Q 版骨架腿总长（髋到脚底）只有 0.50 米 = 座面高 0.50 米，几何上坐着不可能脚着地。
  处理：不降座高（用户定的 0.50），改骨架比例——小腿加长到 28 T（膝轴到地正好 0.50 + 半个腿厚），头同步放大（36 T × 1.1），
  头身比 1 : 1.39，仍在 1:1.3–1:1.5。坐姿眼高几乎不变（0.771 → 0.747），站着变成约 1.97 米（最早的方块人是 1.875 米，场景本来按这个尺度搭）。
  代价：站姿腿比旧 Q 版长，没那么“矮墩墩”；见下面各轮的“比例”条目。

### 看到的差距

人物
1. **头的侧面是一大块平的肤色**：坐着从斜后方、侧面看（`r1-rt-seated` 右边那位、`r1-lab-rt-side`），脸颊到耳朵是一整面平板，下颌线的台阶太弱，还是“方箱子”。
2. **从背后看头发还是一块矩形**：默认机位离镜头最近的几位都是背影（`r1-rt-overview`），深色头发（阿澜、南姐）读成一个大黑方块；圆顶的两级收边在这个距离看不出来。
3. 南姐的棒球帽和头发同色（都是 `#3d3550`），背后看帽子、头发、马尾糊成一团，马尾看不出来。
4. 老苏胡子两侧的“鬓角”是两块突出的灰板，正面像贴了两块砖。
5. 灰先生的后梳低马尾正面像一顶头盔（额前那条发际线发片太平）；侧面看马尾太短太细。
6. K 的寸头颗粒像软木塞的麻点，太碎。
7. 好好的卷团在侧面堆得太大太方，像一摞积木；正面看还可以。
8. 姿态表：思考（手托下巴）那只手被大头挡住看不见；“用道具”那一格头低得太多，脸压扁。
9. 比例：站姿腿比较长（为了脚着地），全身正面看头没有占到一半；坐着的时候看不出这个问题。先接受，用粗腿、大鞋压一点。

椅子
10. 会议木椅在场景里读得出来（浅橡木框 + 灰绿、灰蓝布垫），坐姿贴合：脚在地上、臀在垫上、背贴靠背、大头悬在靠背上方，没有穿模。
11. 实验台的六款椅子：办公椅网布（已改成 64 像素/米的细网眼）、课椅和户外椅偏白（已压暗）——这两项在 r1 之前已经改掉，r1 截图里是改后的样子。
12. 正式软包椅（辩论用）拉扣的十字褶在近处有点像贴纸；扶手软包条太细。

地板
13. 议事厅长条木地板（`r1-rt-floor / planks`）：板宽 25 厘米、长 1.6–3.6 米、相邻两行端缝错开、相邻两块不同色，看不出重复；
    和草席（浅麦色）、白墙、深色梁柱能分开层次。问题：板缝那条暗线（1 像素 = 6 厘米）偏黑偏粗，近看像描了边。
14. 炉床石板每块的痕迹已经改成各不相同（`r1-rt-fire`）。
15. 石木混拼（实验台）是规整的 1 米方格，网格感太强；深胡桃人字拼没有问题。

场景（不在这次范围里、需要用户决定的）
16. 桌面高度 0.95：Q 版坐下以后颈部在 0.94，桌面差不多到下巴，远处几位只有头露在桌面上方，像小孩坐大人的桌子。
    上一位接手人计划把 v2 圆桌降到 0.78。桌子不在“人物、椅子、地板”里，这次没有动，等用户决定。
17. 产品画面（HUD）里是 stage-lab 的 8 个占位角色（`preview-n`，同一种短发、只换衣服色），所以 8 个人长得一样；正式产品里用的是真实人物。

## 第 4 节：数据检查（`npm run test:mc-avatar`）

- 33 人都有固定造型（按人物 id，人物库之外没有多余的）；发型零件 17 种，实际用到 15 种。
- `src/mc/avatar` 里没有随机数、没有时间、没有按 agentId 取外观；同一个发型拼两次完全一样。
- 搭配约束逐条用构造的冲突造型验证（兜帽 / 帽子、耳机 / 丸子头、围巾 / 领带、裙子 / 长外套下摆、背带裤、帽子 / 呆毛、眼镜 / 刘海、兜帽藏头发）。
- 每人主色 3–5 种（相近色算一个，皮肤不算）；33 人的轮廓（发型 + 头饰 + 外层 + 下装 + 呆毛 / 胡子 / 围巾 / 大发结）两两不同。
  r1 时树洞（6 色）、调色盘（6 色）、阿冷（2 色）不合格，已调整：树洞的鞋改成和裤子同色系，调色盘的贝雷帽和发圈改成和裤子同一种藏青，阿冷加浅灰耳机和棕色短靴。
- 坐姿几何：鞋底离地 0；座面前沿 0.11 < 小腿后侧 0.118；靠背前面 -0.125 在外套背面后面；靠背顶 0.80 < 大头后仰 0.4 弧度时的后脑下沿 0.804；扶手和胳膊之间 3.7 厘米。

## 第 2 轮（r2）

改了什么（r1 → r2，对应 r1 的条目号）：
- 1 头：脸那一面两侧竖棱各切掉 2 T（脸板 32 宽贴在 36 宽的头上），斜看、侧看脸颊到侧面有一道转折；头侧面靠后一半暗一档、斜着升到耳下的下颌线；耳朵缩小，去掉一圈圈的框。
- 2 头发：圆顶改成三级（多数发型顶厚 5 T），每级四个竖角切得更多（后角 3→7 T）；深色头发的高光更亮更长（每缕两道竖高光）。
- 3 南姐：帽子改成卡其色帆布帽，短靴跟帽子同色系；背后能看出帽子、马尾、头发三层。
- 4 老苏：胡子改成下巴一块 + 往下收窄的一撮 + 小胡子，两颊只留贴着脸板边的细鬓。
- 5 灰先生：发际线改成三级往中间收的“美人尖”，马尾加粗加长（垂到背中）。
- 6 K：寸头颗粒减到原来的三分之一。
- 7 好好：两侧卷团缩小、贴近头发表面。
- 8 姿态：大头短胳膊，原来的“托腮”“挠头”“伸懒腰”“欢呼”手会插进头里（按骨架算过手的位置）；改成手放在脸颊外侧 / 头两侧（`player.ts` 待机动作和欢呼的胳膊角度）。实验台的“思考”用靠镜头那只手托腮。
- 13 地板：板缝暗线从 0.66 提到 0.74，不再像描边。15 石木混拼改成隔行错开半格、两组石色。
- 12 正式软包椅：拉扣只留扣子，不画十字褶；扶手软包条加宽。
- 调色板：按用户要求收紧到每人 4–5 色（r1 的检查放宽到 3 色是错的）。炮仗、阿麦、算盘、灭火器、钢笔原来只有 3 色，各加一个从设定来的颜色：
  炮仗的球鞋用设定 accent 的橙黄（引信）、阿麦的耳麦酒红（录音的 on air 灯）、算盘的领带枣红（算盘珠）、灭火器夹克里面换成 accent 的米白 T 恤、钢笔的长裤墨水蓝。

截图：`r2-lab-*`、`r2-rt-*`，对比图 `compare-baseline-r2.jpg`。

### 看到的差距

1. 头的侧面：切角以后斜看不再是方箱子；但贴得很近的时候（`r2-rt-seated` 右边那位）侧脸还是一大块平面。当时 Agent 将它归因于方块头限制并暂时保留，此判断不是用户验收。
2. 背影：圆顶更圆了一点，深色头发在默认机位还是比较“一坨”，高光能看出来但弱。当时 Agent 暂时保留且没有添加提亮滤镜，此判断不是用户验收。
3. 帽子（南姐的棒球帽、暖宝宝 / 积木的毛线帽、贝雷帽）帽顶还是一个方盒子，背后看像一块平板，没有圆顶。
4. 石木混拼的错缝在俯视图里不明显，木条交叉处的深色方钉太规则。
5. 桌面高度（同 r1 第 16 条，等用户定）。
6. 动作改动只在实验台的静态姿态上看过；游戏里待机动作“托腮 / 挠头 / 伸懒腰 / 欢呼”是按骨架算的手的位置，没有在场景里拍到这几个瞬间。

## 第 3 轮（r3）

### 看到的差距（交给用户审查前的状态）
