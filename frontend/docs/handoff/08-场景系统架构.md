这套场景不在 Minecraft 游戏里搭建。浏览器里的 Three.js 读取已经导入的方块资源，按设计数据把房间画出来。运行时没有大模型生成场景。

## 保留的能力

这些已经和人物、讨论、碰撞绑在一起，重构没有换掉它们：

- 运行时房间 `Room`（`src/mc/rooms/debate.ts`）。讨论导演、物理、镜头、舞台都读它。
- 方块模型、图集、面剔除、资源导入（`blockModel.ts`、`blockMesh.ts`、`assets.ts`、`scripts/mc-import.mjs`）。材质包仍是 `original` / `hd` / `style`，房间自己指定，实验室可以用查询参数覆盖。
- 人物入座、起身、发言、辩论室的铃和阶段、办公室的走访、会议、站会。
- 外壳 `studio()`、家具工具箱、房间检查 `validateRoom`。

二维场景、讨论调度、人物设定和聊天界面没有改。

## 新的分层

设计在渲染之前，运行时房间是编译结果。

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 尺度 | `src/mc/design/scale.ts` | 这个角色骨架的身高、桌高、圆桌空隙。不要另写一套米制。 |
| 配色 | `src/mc/design/scheme.ts` | 每间房一个方案：地面、墙、木、一种座位布料、一种强调色。 |
| 分区 | `src/mc/design/space.ts` | 有名字的地面，以及圆桌座位环。分区不直接生成网格。 |
| 设计入口 | `src/mc/design/plans.ts` | 六间房的意图、方案、分区和 `build()`。 |
| 房间 | `src/mc/rooms/*.ts` | 各写各的空间。`scenes.ts` 只负责按种类调用。 |

圆桌空隙必须落在 `SCALE.roundGapMin` 和 `roundGapMax` 之间。`npm run test:mc-design` 检查六间房都有意图和分区，办公室仍是 13 个工位、6 把会议椅。

## 六间房现在怎么组织

- **圆桌**：一张桌子、一圈椅子、北墙话题、两角书架。座位转过半格，南面留出镜头的空当。样板，这一轮没有再改造型。
- **辩论室**：主持、正方、反方、中轴通道、赛场、观众。墙的外框没动，因为 `check-mc-physics.mjs` 按这个外框探针。队色只属于双方。辩题板的字曾经被铜框正面挡住，板面已挪到框前面。
- **办公室**：北墙负责人、西北会议角（圆毯，不是一圈橙色方块地毯）、三组并排的工位岛、南端站会。墙柱和悬在半空的方块灯笼去掉了，灯从天花板吊下来。工位椅一种蓝，会议椅一种橙。
- **教室**：北墙讲授。左右各一列、各两排，正中一条通道对着黑板，没有空椅子。座位全部浅蓝。
- **草地**：土路从画面左侧进来，野餐在左中，池塘和芦苇在右侧，樱花单独做一棵焦点。树的位置是写死的，前后错开，不是同一条直线。地面仍大体是一层草，只在三处抬高一格。
- **播客间**：保持原先认可的平涂布景，收成谈话区、背景和角落。没有改成方块房。

## 画面和性能怎么验

先开 `npm run dev`（端口 5173），再：

```bash
node scripts/mc-shots.mjs shoot <标签> debate roundtable office classroom meadow podcast --port=5173 --shots=overview,personA,judge
node scripts/mc-shots.mjs compare <改前标签> <改后标签>
```

照片在 `frontend/.shots/`，不提交。全景指标是高画质、当前机位下的绘制调用、三角面和加载毫秒。换机位会改绘制数，所以它不是整场场景的固定预算，也不是好看分数。

这一轮实际看过的画面：

| 标签 | 用来核对什么 |
| --- | --- |
| `redesign` | 六间房第一版全景。办公室的柱子、方块地毯和灯是在这张上定的问题。 |
| `redesign-office` | 办公室去掉柱子、换成吊灯和圆毯之后的评委视角。 |
| `redesign-b` | 辩题板能读出辩题；教室第一次去掉空椅后，中间的人挡住黑板。 |
| `redesign-c` | 教室中间让开通道；草地全景能同时看到野餐、路和池塘。 |

## 还没当成定论的事

配色和构图是这次实现时的设计判断，不是用户已经点头的方向。

辩论室外墙没有重做。室内的正反方、主持和通道是按这个外框安排的，不是新的一栋建筑。

播客间仍是平涂布景。要不要改成方块建筑，等看过 `redesign/podcast-overview.png` 再定。

人物会轻微卡进方块椅。坐高沿用原来的骨架（坐下根在 1.5），没有为了“像真椅子”另做一套身体。

教室两侧的小黑板是道具，上面只有几道粉笔线，话题在中间那块。草地从野餐的低机位看，北面的树仍然比较齐。这些留着，没有再用装饰去盖。

二维场景、讨论调度和聊天界面没有改，也没有在产品页面里手点一整场讨论。舞台脚本和六个房间的加载、走访、会议、站会检查是通过的。
