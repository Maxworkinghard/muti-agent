# 圆桌会议室 v2 ——「湖畔木构议事厅」静态视觉样板

本阶段只做圆桌会议室一个场景的静态视觉样板；另外五个场景、人物复杂行为都没动。
功能契约见 `00-contract.md`，新实现全部在 `src/mc/v2/`，旧场景仍是默认。

## 怎么看

| 用途 | 地址 / 命令（开发服务端口按实际，Max 上是 5173） |
|---|---|
| 场景实验页（封面模式） | `http://localhost:5173/mc-lab.html?scene=roundtable&v=2`（加 `&cover` 去掉界面） |
| 产品画面（带名字牌、按钮） | `http://localhost:5173/stage-lab.html?scene=roundtable-mc&v=2` |
| 旧版对照（默认，不带 v） | `mc-lab.html?scene=roundtable`、`stage-lab.html?scene=roundtable-mc` |
| 渲染截图 | `node scripts/mc-shots.mjs shoot <标签> roundtable --v=2 --port=5173 [--quality=high\|medium]` |
| 契约检查 | `npm run test:mc-v2` |

开关只在 `McStage3D` 的 `version` 属性上：`version={2}` 时 `buildMcRoomV2(kind)`，返回 null（没有 v2 实现的场景）就退回 `buildMcRoom(kind)`。
两个预览页从地址栏 `v=2` 读这个值；正式工作台没有传 `version`，所以产品里仍是旧场景。

`scripts/mc-shots.mjs`（`--v=2`、`--quality=`）、`scripts/mc-shots.cams.json`（`roundtable@v2` 机位）、`package.json`（`test:mc-v2`）。

## 设计

**空间**（1 格 = 1 米，x 向东、z 向南，人踩在 y=1）

- 湖在北面。厅坐在一圈比草地高 1 格的石基座上，北沿是伸进湖里的石砌驳岸。
- 主厅 x 6–19、z 4–15；屋面从 z=3 起挑出一格檐，z 1–2 是不加顶的临水平台（两根灯柱各挂一盏小纸灯）。柱网 x∈{6,10,15,19}、z∈{4,7,12,15}，厅内没有柱子。
- 双坡屋顶，屋脊南北向，**山墙正对湖面**：从厅里往北看，横梁下是湖面和对岸，梁上的三角山花里是远山和天。
  北山花不封板，只有一根中柱（king post）；南山花白灰封板。
  默认机位在西南角、人眼略高（y≈3.45），朝东北看：前景是梁和檩条，中景是桌子和八个人，远景是湖、对岸林带；
  远山和天在观摩位、外景和话题匾近景里更完整（见下面“剩余差距”）。
- 桌子正上方升起一座八角天窗楼（井壁白灰 + 深色腰枋 + 上两层格窗 + 四坡小瓦顶 + 中间玻璃天窗），大纸灯从楼顶垂下。
- 东墙中间一跨是石砌壁炉（炉膛朝西、石炉床、木壁炉台），烟囱穿出东坡；东墙其余两跨是格窗。
- 西面敞开（半高石栏 + 中间台阶），下午低角度的太阳（方位 200°、仰角 22°）从西檐下斜射进来，柱影拉过地板；
  西南一跨放下半幅芦苇帘，帘缝把阳光切成条纹。
- 南墙（默认机位背后）：石勒脚 + 中间一跨书架 + 两侧格窗，山花白灰封板。和东侧壁炉形成不对称。

**材料**：深色橡木框架（柱、梁、檩、封檐板）+ 浅色白桦地板和望板 + 白灰墙 + 浅灰方石基座和壁炉 + 板岩瓦 +
布垫（八种颜色）+ 草编席 + 植物。框架深、面层浅，靠明度对比而不是靠整体暖色调出“温馨”。

**家具**：八角厚桌面（胡桃色，浅色镶边）+ 石砌八角桌座；八把白桦木椅，三档靠背，布垫和靠垫颜色各不相同；
桌上一套茶具（托盘、茶壶、每人一只杯子和一张便笺、少数人面前一卷卷轴）。

**话题匾**：挂在北面横梁下（`layout.board`，朝 +z），米白纸面、双线边框、左上厅名、中间大字议题（最多两行）、
左下朱红阶段、底边在座的人、右下一方朱印。

**灯**：桌上大纸灯（暖）、壁炉火（橙，投影）、临水平台两盏灯柱小纸灯；天空、湖面和远山是冷色。
不用泛光/饱和度/暖色滤镜替代美术：`look.saturation=1`，后期只有渲染器原有的轻微泛光和接触阴影。

## 迭代记录（渲染 → 对照 → 修）

截图都是 Max 上 `mc-shots.mjs` 用无头 Chrome（swiftshader 软件渲染）拍的，1440×960，`--v=2`。
每轮的文件在 `docs/rebuild/roundtable-v2/rN-*.png`：overview（默认机位）、fixed（固定外景机位，湖面看厅）、
west / seated / fire / tea / roof / board（细节）、judge（观摩位）、hud（产品画面带名字牌）。
对照参考：旧版 `docs/rebuild/baseline/`（旧圆桌）；新旧对照拼图 `roundtable-v2/compare-old-new.jpg`和设计方向“湖畔木构议事厅”。下表的数值是 overview 的平均饱和度 / 亮度中位数 / 暗像素（亮度<40）占比。

| 轮 | 数值 | 看到的差距（空间层次 / 材质 / 光影 / 景深 / 比例） | 改了什么 |
|---|---|---|---|
| r1 | .72 / 52 / 39% | 整体偏暗偏橙（橙色像素 27%）；台阶式屋面太厚重；天窗楼像一座黑塔；远景几乎看不见；草地是一整块平面；湖面纹理太花 | 色板整体提亮、降饱和、偏冷：白桦地板、白桦望板、白灰墙；加封檐板和博风板；地面换成方块草地并在远景平台挖洞；山更低更近；湖面纹理变稀；曝光 1.12、太阳仰角 22°；去掉常春藤吊篮 |
| r2 | .57 / 70 / 36% | 明显变干净。但屋顶仍占画面上三分之一、室内看不到天和山；天窗楼仍黑且方；茶具粗糙；对岸台地侧面是土褐色、平原空 | 机位抬头；天窗楼加楼梯式瓦帽；台地侧面改橄榄绿；近岸散布树丛；茶具按像素尺寸重做（壶盖、壶嘴、把手、每人托盘杯）；加樱花枝 |
| r3 | .62 / 59 / 44% | 樱花枝成了一块块粉色大纸片，删掉；找到远景被挡的原因：前廊上方的山花挑檐一直伸到 z=1，室内视线穿过山花三角正好打在挑檐底板上 | 见 r4 |
| r4 | .63 / 56 / 45% | 屋面从 z=3 起，前廊变成不加顶的临水平台；去掉前廊角柱和侧梁外伸；加北山花中柱；天窗楼降到 10、顶圈改白灰；座位相位 π/6，让镜头从两人之间看进去；平台灯改成灯柱。结果：湖面、对岸、匾、壁炉、八人都在画面里，外景比例舒服。剩余：上方深色梁架仍占大块；西檐下封檐板和白桦台阶面重叠闪烁 | 见 r5 |
| r5 | .58 / 66 / 40% | 机位降到 y 3.45、略低头，地板上的柱影和阳光条纹进入画面，梁架占比下降；中/高画质对比（见下） | 封檐板外移 0.16 m 消除 z-fighting；间接光 .3→.4 |
| r6 | .57 / 67 / 39% | 西檐封檐板成了一条完整的深色带，闪烁消失；间接光提高后暗部只略微抬起（暗像素 40%→39%），主要暗区是近处梁架，属于前景层，保留 | 定稿 |

**中 / 高画质**：`r5-medium-*.png` 与 `r5-*.png` 在 swiftshader 下几乎一样（overview 平均逐像素差 0.68/255，差异 >16 的像素 0.1%）。
这说明 v2 的画面不依赖高画质专属效果；但在软件渲染下没法验证真实 GPU 上中/高画质的阴影分辨率、软阴影和后期差异。

### swiftshader 验证不了的
- 帧率和真实 GPU 上的开销（swiftshader 一次 10 张图约 4 分钟，只能看静帧）。
- 阴影贴图分辨率 / 软阴影边缘在高画质下的真实观感，中/高画质差异。
- 壁炉火和纸灯闪烁的动态效果（只拍到某一帧）。
- 人物走动、发言动画在 v2 场景里的观感（本阶段只保证坐姿、发言契约和路径检查通过，`test:mc-v2`）。

### 剩余差距
- 默认机位里远山和天空只在开口缝隙里露一点：桌子上方的天窗楼和 z=7 的横梁挡住了北山花三角。观摩位、外景、话题匾近景能看到完整的湖–林–山–天。
- 近处两人的背影会挡住一部分桌面（坐满八人时任何室内机位都有这个取舍）。
- 天窗楼外观仍偏方正；壁炉台上的小摆件在默认机位下太小、读不清。
- 新默认机位里人物占画面比例比旧版小（旧版是俯视剖面，人物和桌子占满画面）；名字牌在产品画面里仍清楚（`r6-hud.png`）。
