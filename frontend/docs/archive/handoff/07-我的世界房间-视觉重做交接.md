## 1. 用户要什么（按时间）

1. **最早的版本**（Faithful 64x 材质、写实道具、平视机位）：用户觉得庄严肃穆、一本正经、又土又老气。
   重点：要在视觉上欢快、青春的环境里跑讨论机制；对照 `public/scenes/scene-*.png` 那几张二维场景，它们色彩丰富、好看；
   要求非 AI 感、非廉价感；可以不被手册限制。
2. **第一轮重做**（照二维原图：剖面俯视、平涂色板重画方块贴图、圆角玩具家具）：用户说"介于原来的和我想象中的之间，还没达到预期"，
   只有**播客访谈间"还不错"**。
3. **第二轮**：照播客间的思路，改成正面稍高的机位、人物是画面主体、墙面有层次、暖色灯光。
4. **第三轮（现在的样子）**：用户发来一组光影/材质包截图（日式神社和村落、花海、樱花湖、海岸悬崖、雪夜小屋），
   原话："建议你去学学这种配色，或者直接去用别人的好模组（modrinth.com、curseforge.com/minecraft），别老是旧思想"。
   这些图的共同点：**原版方块搭建 + 好的材质包（三维蓬松树叶）+ 光影包式的光线**（实在的太阳影子、蓝天、远处薄雾），
   配色是自然清新的嫩草绿、深树绿、浅色石头和木头、白墙深梁，不是平涂的粉彩色块。
   用户同意下载 Better Leaves（MIT），说"版权问题最后再声明，现在先做"。

所以现在除播客间以外的五个房间都改成了**原版方块贴图 + Better Leaves + 屋顶挡光、窗户进光的阳光**，
机位沿用第二轮的正面稍高机位。播客间保持第一轮的平涂样子（用户认可的），要不要也改成真实方块还没问。

## 3. 现在的代码状态（未提交，main 的工作区）

另外有人在 10-07 晚上到 10-08 凌晨改过：全站色票（`src/styles.css`）、默认材质改成 `style`（`public/mc/style/` 的像素重绘图集，
现在只有不指定 `material` 的房间才会用到——六个房间都指定了，所以只在 Lab 里能看到）、户外 Sky 天空、
`public/scenes/scene-podcast.png` 换成扁平插画。这些没有回退。

### 3.1 外壳、机位、光线

- `src/mc/rooms/studio.ts`：房间外壳 `studio()`。`shell` 直接指定外壳各部位的方块（地板、踢脚、墙、檐口横梁、天花板、每隔几格一根的原木柱），
  `build(b,cut)` 往房间里加方块（地毯、书架、木桶、盆栽、挂着的灯笼……）；`palette`+`paint` 是平涂重画的老办法（只有播客间在用）。
  `open:true` 南面敞开并把地面往外多铺两格。
- `src/mc/rooms/debate.ts`：`Room` 接口。新字段：`material`（这间房用哪套方块贴图，`original` = 原版 + 叠加材质包）、
  `frontal`（正面机位：全景直接看向 `cameraTarget`）、`makeTable`（辩论室的队桌由房间自己做）、`floorOverlay`（地面图只是一层透明的线）、
  `work.overflow`（办公室会议椅坐满后多出来的人站哪）。
- `src/mc/style.ts` 的 `Look`：`roof`（一块只投影、不画出来的屋顶板，阳光只从窗户进屋）、`tint`（草和树叶的生物群系颜色）、
  `haze`/`fog`（户外远处的薄雾）、`skyTop`（户外渐变天穹和像素白云，代码在 `src/mc/sky.ts` 的 `createSkyDome`）。
- `src/components/McStage3D.tsx`：房间指定的 `material` 传给资源加载；不用色板的房间按生物群系给草和树叶染色
  （樱花、杜鹃叶子不染，见 `src/mc/blockMesh.ts` 的 `UNTINTED`）；窗玻璃单独建网格、不投影；屋顶挡光板；户外天穹。
- `src/mc/camera.ts`：`frontal` 房间的全景直接看向 `cameraTarget`。
- `src/mc/rooms/physics.ts`：地毯、睡莲叶这种贴地的薄片（顶面不到 0.1 米）不再挡路（办公室会议角铺了地毯）。

### 3.2 道具

- `src/mc/props/furniture.ts`：`createKit(src)` 道具工具箱。除了平涂圆角块（`box`/`cyl`/`pixels`），还有
  `block`/`blockCyl`（从方块图集切贴图、按每米 16 像素平铺的方块件）和 `painting`（原版的画，云杉木框）。
  贴方块贴图的家具：`blockArmchair` 羊毛扶手椅、`blockRoundTable` 圆桌、`blockDesk` 方桌、`blockSeat` 课椅、
  `blockOfficeChair` 办公椅、`blockPlant` 陶土盆栽、`blockBench` 长凳。
  平涂家具只留下播客间、话题板和桌面小物还在用的（扶手椅、话筒、ON AIR 灯箱、吸音板、收音机、落地灯、马克杯、纸、书……）。
- `src/mc/props/blockKit.ts`：上面那几个方块件的实现。
- `src/mc/props/styledProps.ts`：除辩论室外房间的物件（地面图、原版水面、家具、会滑的椅子、话题板）。
- `src/mc/props/debateProps.ts`：辩论室的物件（拉杆红石灯、讲台、桌铃、辩题板这些交互件不变）；房间给了 `makeTable`/`makeChair` 就用房间的。

## 4. 怎么验证

```bash
cd frontend
npx tsc --noEmit -p .
npm run build
for f in scripts/check-*.mjs; do node "$f" || echo "FAIL $f"; done
```

写这份文档时（10-08）以上全部通过，12 个检查脚本都是 0 退出；`check-mc-look.mjs` 改成了现在的设计
（每间房有光线、用真实方块或色板、前墙能藏、室内屋顶挡光、不靠投影灯、话题板各不相同）。

看画面：`npm run dev`（端口 5180），打开 `/stage-lab.html?scene=<房间>-mc`（debate、roundtable、office、classroom、meadow、podcast）。
批量截图的脚本在 `.verify/mc-redesign/`（无头 Chrome，软件渲染，每间约 25 秒）：

- `node capture.mjs <输出目录名> [debate-mc office-mc ...]`：截 stage-lab 的默认全景；
- `CAMS='{"office-mc":{"pos":[x,y,z],"target":[x,y,z],"fov":30}}' node explore.mjs <目录> office-mc`：临时换机位试构图；
- `node cover.mjs <目录>`：用 mc-lab 的封面模式（`?cover`，不显示界面）截 1440×960 原图，缩成 960×640 放到 `public/mc/preview-<房间>.jpg`。

**`.verify/` 不要提交**：里面有无头浏览器的配置目录（含登录数据、历史记录）和下载的原始文件。
