## 素材取舍

| 素材 | 判断 | 处理 |
|---|---|---|
| 产品场景图、图集、字体、音效、叠加包及许可 | 有运行或来源用途 | 留在 public / mc-packs，不移入归档 |
| README 四张产品截图 | 有使用说明用途 | 留在根目录 docs/screens |
| 用户参考原图 | 用户决策依据 | 仓库未追踪原图；不从本地私人文件搬入 |
| art / rebuild 的旧版基线 | 能解释人物、坐姿与房间改动 | 保留原图和拼图 |
| 各轮默认图、细节图及比较拼图 | 能解释记录中的结构、材质或机位变化；部分方案未决 | 归档保留，不宣称无价值 |
| art/sample/wip-r0 | 正式轮次前的开发过程，已被后续实现替代 | 无当前设计依据用途；留作旧头发/脚踏等失败的追溯 |
| r7 中画质整体、固定外景、HUD、炉火、坐姿 | 画质对照代表集；炉火和坐姿差异较明显 | 保留中/高成对图 |
| r7 中画质 board / lake / roof / tea / west | 与保留的高画质图信息高度重叠，没有独立方案；软件渲染不能证明硬件画质 | 清理这五张额外采样，保留高画质图及差异指标 |
| 三张 r3 与 r2 完全相同的截图 | 无增量图像信息 | 已去重，映射见样板记录 |

“没有当前参考用途”不等于“没有历史价值”。这次整理只精简有替代证据的采样；完整文件记录、判断依据与 Git 恢复点见[维护审计](../../../docs/MAINTENANCE_AUDIT.md)。
